# Template Mural — Workshop 4D de Aprofundamento e Ideacao

> **Nota:** este template nao utiliza emojis, em conformidade com a politica zero emojis do ERIC (ADR-012). As dimensoes sao identificadas por codigos de cor e nomes.

Este documento descreve a estrutura do board Mural a ser criado automaticamente pela skill `facilitate_4d_workshop`. O board segue a metodologia 4D e serve como suporte visual e colaborativo para o workshop.

Use o board para D1–D4 em qualquer fase. Se a rodada for retomada, registre versão e data de cada contribuição; no RC6, o relatório completo pode alimentar o BP1.

---

## Visao geral do board

O board e dividido em **6 areas** principais, dispostas em fluxo horizontal (da esquerda para a direita):

```
+----------+  +----------+  +----------+  +----------+  +----------+  +----------+
| ABERTURA |  | D1       |  | D2       |  | D3       |  | D4       |  |FECHAMENTO|
| Contexto |->| PERCEPCAO|->|DIAGNOST. |->| DESENHO  |->| DECISAO  |->| Outputs  |
| 5 min    |  | 20-25min |  | 60-70min |  | 45-50min |  | 25-30min |  |          |
+----------+  +----------+  +----------+  +----------+  +----------+  +----------+
```

---

## Area 1 — Abertura

**Cor:** Cinza claro (#E0E0E0)
**Posicao:** Canto superior esquerdo

### Elementos

| Elemento | Tipo | Conteudo |
|---|---|---|
| Titulo do board | Texto grande | "Workshop 4D: [nome do desafio]" |
| Contexto | Texto | Resumo do desafio com fonte e versão, de qualquer fase |
| Participantes | Lista | Nomes ou quantidade de participantes |
| Timer | Widget | 3 horas |
| Regras do workshop | Post-it | "Todas as ideias sao bem-vindas", "Sem julgamento", "Foco no problema" |

---

## Area 2 — D1: Percepcao (Unfreeze)

**Cor:** Amarelo (#FFF3CD)
**Posicao:** Apos abertura, lado esquerdo
**Tempo:** 20-25 min

### Subsecao 2.1 — Elefante na Sala

| Elemento | Tipo | Conteudo |
|---|---|---|
| Titulo da secao | Texto | "[D1] Elefante na Sala" |
| Instrucao | Texto | "O que nao esta sendo dito? Escreva anonimamente um post-it." |
| Zona de post-its | Area livre | Participantes arrastam post-its anonimos |
| Pergunta-guia | Post-it fixo | "Se pudesse dizer uma coisa que ninguem esta falando, qual seria?" |

### Subsecao 2.2 — Mapa Emocional

| Elemento | Tipo | Conteudo |
|---|---|---|
| Titulo da secao | Texto | "[D1] Mapa Emocional" |
| Instrucao | Texto | "Em uma palavra, qual sentimento domina voce em relacao a esse desafio?" |
| Grade de sentimentos | Grid 3x3 | Pre-preenchido com: Ansiedade / Esperanca / Cansaco / Empolgacao / Medo / Confianca / Frustracao / Curiosidade / Outro |
| Zona de post-its | Area | Participantes agrupam por sentimento |

## Area 3 — D2: Diagnostico (Diagnose)

**Cor:** Azul claro (#CCE5FF)
**Posicao:** Centro-esquerda
**Tempo:** 60-70 min

### Subsecao 3.1 — Jornada do Usuario

| Elemento | Tipo | Conteudo |
|---|---|---|
| Titulo da secao | Texto | "[D2] Jornada do Usuario" |
| Instrucao | Texto | "Desenhe a jornada de quem vive o problema" |
| Linha do tempo | 3 colunas | **Antes** / **Durante** / **Depois** |
| Coluna Antes | Area de post-its | Pergunta: "Como era antes? Quem faz o que?" |
| Coluna Durante | Area de post-its | Pergunta: "O que acontece no momento critico? Onde estao as dores?" |
| Coluna Depois | Area de post-its | Pergunta: "Qual o resultado? O que melhora ou piora?" |

### Subsecao 3.2 — Barco da Inovacao

| Elemento | Tipo | Conteudo |
|---|---|---|
| Titulo da secao | Texto | "[D2] Barco da Inovacao" |
| Ilustracao do barco | Desenho | Esboco de um barco com 4 areas |
| **Ventos — Impulsionadores** | Area verde | "O que nos impulsiona? Forcas, dados, tendencias" |
| **Ancoras** | Area vermelha | "O que nos trava? Resistencias, limitacoes" |
| **Icebergs — Riscos** | Area laranja | "O que pode dar errado? Suposicoes nao validadas" |
| **Porto — Futuro desejado** | Area roxa | "Onde queremos chegar? Cenario ideal" |

## Area 5 — D4: Decisao (Decide)

**Cor:** Roxo claro (#E8D5F5)
**Posicao:** Direita
**Tempo:** 25-30 min

### Subsecao 5.1 — Apresentacao

| Elemento | Tipo | Conteudo |
|---|---|---|
| Titulo da secao | Texto | "[D4] Decisao" |
| Resumo consolidado | Texto | Copias das propostas da area D3 |

### Subsecao 5.2 — Alocacao de Capital

| Elemento | Tipo | Conteudo |
|---|---|---|
| Instrucao | Texto | "Voce tem 10 creditos para investir. Pode distribuir ou concentrar; use todos e so invista no que topa defender." |
| Tabela de propostas | Grid | Lista de propostas com espaco para votos |
| Votos | Sticky notes numericos | Distribuicao simultanea de 10 creditos; registre participante, proposta e quantidade e confira o total alocado |
| Totalizador | Calculo automatico | Soma dos investimentos por proposta |

### Subsecao 5.3 — Verificacao de Consistencia

| Elemento | Tipo | Conteudo |
|---|---|---|
| Titulo | Texto | "[D4] Verificacao de Consistencia" |
| Defesa da prioridade | Pergunta aos investidores | "Quem investiu 3 creditos ou mais? Por que essa proposta merece prioridade? Qual risco voce esta disposto(a) a assumir?" |
| Checklist complementar | Lista de verificacao | [ ] As propostas enderecam as ancoras? [ ] Aproveitam os ventos? [ ] Mitigam os riscos? |

## Notas de implementacao

- O board deve ser criado via `mcp.mural.write.create_board` com confirmacao do usuario.
- As secoes e subsecoes devem ser criadas via `mcp.mural.write.create_section`.
- Post-its modelo e fixos sao criados via `mcp.mural.write.create_sticky_note`.
- Ao final do workshop, os outputs sao extraidos via `mcp.mural.read.get_sticky_notes` e `mcp.mural.read.get_board`.
- Em caso de indisponibilidade do Mural, a skill opera apenas em modo conversacional.
